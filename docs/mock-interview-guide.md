# 모의면접 진행 가이드

## 30분 버전

- 5분: 자기소개 / 프로젝트
- 10분: CS 핵심 질문 5개
- 10분: 게임 서버 / 네트워크 질문
- 5분: 약점 질문 재공격

## 60분 버전

- 5분: 자기소개
- 15분: C++ / OS
- 15분: Network / Concurrency
- 10분: DB / Redis
- 10분: Game Server System Design
- 5분: 프로젝트 딥다이브

## 규칙

1. 질문을 본 뒤 10초 이상 침묵하지 않습니다.
2. 모르면 아는 범위를 먼저 말합니다.
3. 면접 중 검색하지 않습니다.
4. 끝난 뒤에만 정답을 확인합니다.
5. 틀린 질문은 `review` 후보로 남깁니다.

## 압박 꼬리질문 예

- 왜 그렇게 설계했나요?
- 다른 방법은 없나요?
- 연결이 10배 늘어나면요?
- 서버가 중간에 죽으면요?
- 패킷이 두 번 오면요?
- 순서가 바뀌면요?
- 한 유저가 악의적으로 요청하면요?
- 락 경합이 심해지면요?
- DB가 느려지면요?
- Redis가 죽으면요?
