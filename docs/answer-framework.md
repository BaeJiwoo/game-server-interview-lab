# 기술 면접 답변 프레임워크

## 1. 정의
질문에 대한 한 문장 답변.

## 2. 왜 필요한가
해결하려는 문제를 말합니다.

## 3. 어떻게 동작하는가
내부 흐름을 순서대로 설명합니다.

## 4. 장단점
항상 trade-off를 같이 말합니다.

## 5. 서버에서의 사용 예
게임 서버 문맥으로 연결합니다.

## 6. 내 경험
직접 구현하거나 디버깅한 사례를 붙입니다.

## 좋은 답변의 특징

- 첫 문장에서 결론이 나온다.
- 기술 용어를 다시 기술 용어로만 정의하지 않는다.
- 데이터/스레드/패킷이 **어디에서 어디로 이동하는지** 말한다.
- "빠르다" 대신 **왜 빠른지** 설명한다.
- 항상 실패 상황을 하나 생각한다.
