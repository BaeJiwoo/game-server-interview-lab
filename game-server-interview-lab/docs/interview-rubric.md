# 면접 답변 평가표

각 질문을 0~3점으로 평가합니다.

## 0점 — 모름
- 용어 자체가 낯설다.
- 설명 도중 핵심 개념이 틀린다.

## 1점 — 정의
- 한 문장 정의 가능.
- 대표 사용처를 안다.
- 꼬리질문에는 흔들린다.

## 2점 — 원리
- 내부 동작을 순서대로 설명한다.
- 장단점과 선택 기준을 말한다.
- 간단한 꼬리질문에 대응한다.

## 3점 — 실전
- 코드/구조까지 설명할 수 있다.
- 장애/성능 문제를 예측한다.
- 대안 기술과 trade-off를 비교한다.
- 실제 프로젝트 경험과 연결한다.

## 면접관 관점 체크

- 정확성
- 구조성
- 깊이
- 실무 연결
- 의사소통
- 모르는 범위를 인정하는 태도

## 답변 종료 기준

좋은 기술 답변은 보통 아래에서 끝냅니다.

> "그래서 이 상황에서는 A를 사용하겠습니다. 다만 B 문제가 생길 수 있으므로 C 방식으로 보완하겠습니다."

이 한 문장이 나오면 지식 나열이 아니라 **기술 선택**까지 설명한 것입니다.
